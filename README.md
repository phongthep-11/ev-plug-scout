# ⚡ EV Plug Scout - EV Station Availability Checker (Thailand)

แอปพลิเคชันสำหรับตรวจสอบสถานะตู้ชาร์จรถยนต์ไฟฟ้า (EV) ว่าง/ไม่ว่าง แบบเรียลไทม์ พร้อมระบบผู้ช่วยเสียง AI สั่งงานและแจ้งเตือนอัตโนมัติขณะขับขี่ ออกแบบโดยโฟกัสการใช้งานจริงบนรถยนต์ (Driving Mode)

---

## 📱 ฟีเจอร์ที่พัฒนาแล้วพร้อมใช้งาน (Current Features)

1. **ถอดแบบ UI ตามต้นแบบ 100% (Dark Driving Mode):**
   - ธีมสีดำสบายตา ไม่แยงตาขณะขับรถกลางคืน
   - แสดงสถานีชาร์จตามเส้นทางหลัก (สายพระราม 2 มุ่งหน้าเพชรบุรี/ชะอำ)
   - ป้ายระบุสถานะสีชัดเจน: **ว่าง (สีเขียว)**, **เต็ม/มีคิว (สีส้ม)**
   - ความเร็วหัวชาร์จ (120 kW, 150 kW, 160 kW, 360 kW Ultra Fast)

2. **ระบบผู้ช่วยเสียง AI โต้ตอบภาษาไทย (Thai Voice Assistant & TTS):**
   - **แตะปุ่ม "ถามเลย":** ผู้ช่วย AI ตอบสถานะตู้ชาร์จด้วยเสียงพูดภาษาไทยสังเคราะห์ (Web Speech Synthesis)
   - **รองรับคำสั่งเสียง (Web Speech Recognition):** สามารถพูดถาม เช่น *"ปั๊มข้างหน้าว่างไหม?"*, *"หาตู้ว่างใกล้สุด"*, *"มีตู้ Ultra Fast ไหม?"*
   - หากตู้สถานีข้างหน้าเต็ม ระบบจะแนะนำสถานีถัดไปที่มีตู้ว่างให้อัตโนมัติ

3. **โหมดจำลองการขับขี่บนถนนจริง (Drive Simulator):**
   - ปุ่ม **"โหมดจำลองขับ"** ด้านบน จะจำลองการขับรถตามเส้นทางพระราม 2
   - เมื่อรถวิ่งเข้าใกล้สถานีในระยะ 2.5 กิโลเมตร ระบบจะส่งเสียงแจ้งเตือนสถานะตู้ว่างให้ฟังอัตโนมัติ โดยที่ผู้ขับขี่ไม่ต้องละสายตามามองหน้าจอ

4. **หน้ารายละเอียดสถานี (Station Details Sheet):**
   - แจกแจงสถานะหัวชาร์จแต่ละช่อง (CCS2, Type 2, CHAdeMO) พร้อมรุ่นรถที่กำลังชาร์จและเวลารอโดยประมาณ
   - อัตราค่าบริการช่วง On-peak / Off-peak (TOU)
   - สิ่งอำนวยความสะดวกในปั๊ม (7-Eleven, Café Amazon, ห้องน้ำ)
   - ปุ่มลัด **"นำทางด้วย Google Maps"** ส่งพิกัดเปิดแอปแผนที่นำทางได้ทันที

5. **แท็บระบบเพิ่มเติม:**
   - 📍 **สถานีบนทาง:** รายการสถานีตามแนวเส้นทาง
   - 🔖 **บันทึกแล้ว:** รายการสถานีโปรดที่บันทึกไว้
   - 🛣️ **วางแผนชาร์จ:** วางแผนจุดแวะชาร์จล่วงหน้า
   - 🚗 **รถของฉัน:** เลือกรุ่นรถ (BYD, Tesla, Deepal, ORA, MG, Volvo) และตรวจเช็กระยะทางที่เหลือตาม % แบตเตอรี่

## 🚀 วิธีเปิดใช้งาน

โปรเจกต์เปิดเซิร์ฟเวอร์รันอยู่แล้วที่:
- **บนคอมพิวเตอร์:** [http://localhost:5173/](http://localhost:5173/)
- **บนมือถือ (เชื่อมต่อ Wi-Fi เดียวกัน):** `http://192.168.68.8:5173/`

คำสั่งสำหรับรันด้วยตัวเองในภายหลัง:
```bash
# ติดตั้ง dependencies
npm install

# รันโหมด Development
npm run dev

# บิลด์สำหรับ Production
npm run build
```
